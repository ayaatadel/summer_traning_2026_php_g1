======== Sql Injection 
Query Parameters:
  1. Named Parameters  (:name) 

    Ex: 
    $query = "SELECT * FROM users WHERE email = :email";
     $stmt = $connection->prepare($query);
    $stmt->execute([
    ':email' => $_POST['email']
    ]);
    $user = $stmt->fetch(PDO::FETCH_ASSOC);

  2. Positional Parameters (?)

    Ex:
    $query = "SELECT * FROM users WHERE email = ? AND id = ?";
    $stmt = $connection->prepare($query);
    $stmt->execute([
        $email,
        $id
    ]);
